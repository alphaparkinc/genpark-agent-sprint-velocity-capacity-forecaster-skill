# genpark-agent-sprint-velocity-capacity-forecaster-skill

Agile engineering sprint capacity and bottleneck forecaster simulating commitment feasibility, PTO impact, and technical debt risk distribution.

## Architecture
- **Input**: Planned story points, developer headcounts, PTO allocations, and technical debt ratio.
- **Engine**: Historical capacity burn-down model and overcommit estimator.
- **Output**: Completion probability and point descoping recommendation.
